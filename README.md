# hotel-web

A hotel website — home, rooms, services, blog and contact pages. Demo site, not a real hotel.

Made this a while back mostly to practise Sass. Styles are written in `sass/` and compile down to `css/`.

## Try it

```bash
git clone https://github.com/justminkuu/hotel-web.git
cd hotel-web
open index.html
```

The compiled CSS is already committed so it works straight away. To change the styling, edit the files in `sass/` and recompile:

```bash
sass sass/style.scss css/style.css --watch
```
